# 数据开关监控

## 结论

本机（realme RMX3700，Android 16 / realme UI 7.0 / ColorOS 16.0.3.503）移动数据开关自己打开，主要是 **WLAN 助理 → 智能切换移动数据**，不是病毒，也不是普通第三方 App。

Android 8 起，第三方不能程序化打开/关闭「移动数据」开关（需要 `MODIFY_PHONE_STATE` / 系统签名）。商店里的聊天、视频、VPN 应用做不到这件事。

## 排查摘要（ADB，只读）

当时状态：`mobile_data=0`（总开关关），Wi-Fi 已连接；无障碍未开；无第三方 Device Owner。

`MODIFY_PHONE_STATE` / `WRITE_SECURE_SETTINGS` 仅系统/ColorOS 包持有。本应用 `com.example.mobiledatanotifier` 只有读电话状态、悬浮窗、使用情况访问，不能改数据开关。

ColorOS 16 把 WLAN 助理放在独立应用 `com.oplus.wirelesssettings`。系统设置 → WLAN → 右上角往往看不到入口。可用：

```bash
adb shell am start -a wireless.settings.WLAN_ASSISTANT_SETTINGS
adb shell am start -a wireless.settings.SLA_SETTINGS
```

ADB（shell）可以 `settings put global <key> 0`；普通 App 不行。

容易误判：移动数据总开关关闭时，仍可能有 IMS/VoLTE 蜂窝连接，状态栏 5G 不等于「上网开关开着」。

## 与设置页对齐（当前监控）

会自动打开「移动数据」开关的 **只有智能切换移动数据**。

| 设置页文案 | Global 键 | 会打开数据开关？ | 悬浮窗闪动 | 主界面展示 |
|-----------|-----------|------------------|------------|------------|
| **智能切换移动数据** | `wifi_auto_change_network` | **是** | **仅此项** | 是 |
| 双通道网络加速 | `wifi_sla_switch_on` | 否 | 否 | 是 |

已从监控去掉（本页其它项或隐藏键，不会单独拨数据开关）：

| 项 / 键 | 说明 |
|---------|------|
| 智能连接最佳 WLAN / `oplus_customize_wifi_smart_connect` | 用户要求去掉 |
| 双 WLAN 网络加速 / `dual_sta_switch_on` | 用户要求去掉 |
| `wifi_auto_change_access_point` | 自动换热点，设置页无对应行 |
| `auto_wifi` | 自动开 Wi-Fi，设置页无对应行 |
| `SLA_AUTO_ENABLED` | 系统内部双通道标记 |

旧逻辑曾把隐藏键也当成「助理开启」，造成误报。

## 权限边界

| 能力 | 第三方能否做 |
|------|----------------|
| 读 `Settings.Global` 上述键 | 能，无需新权限 |
| `ContentObserver` 监听 Global 变化 | 能 |
| `Settings.Global.putInt` / `settings put` 关掉它们 | 不能，需要 `WRITE_SECURE_SETTINGS` |
| 调起 WLAN 助理 / 双通道设置页 | 能（隐式 Intent，已在 Manifest `<queries>` 声明） |
| 精确到「哪个第三方包拨了数据开关」 | 不能；系统不提供调用方包名 |
| 开关变化时的前台应用名 | 能（`PACKAGE_USAGE_STATS` + `queryEvents`），仅为关联 |

因此本应用的「去关闭」按钮只打开对应设置页，由用户手动关。未声明 `WRITE_SETTINGS` / `WRITE_SECURE_SETTINGS`。

## 本应用已实现

1. `WlanAssistantMonitor`：只读智能切换移动数据、双通道网络加速。
2. 悬浮窗：仅当移动数据开，或 `wifi_auto_change_network=1` 时红绿硬切闪动。
3. 主界面 WLAN 卡片：两项开/关；红色提示只在「智能切换移动数据」为开时出现。
4. 数据开关记录（内存环形缓冲，约 50 条，不落盘）：
   - `OverlayService` 用 `TelephonyCallback.UserMobileDataStateListener`（API 31+）、`mobile_data` ContentObserver、3 秒轮询检测开/关。
   - 变化时用 `UsageStatsManager.queryEvents` 取前后约 10 秒前台应用。
   - `systemui` / `settings` / `phone` / `wirelesssettings` 显示为「系统界面」。
   - 主界面可滑动查看（整页 ScrollView）；可清空。进程被杀后记录消失。
